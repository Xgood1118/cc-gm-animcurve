# animcurve

只允许标准库。保留骨架中的公开名字与签名。

- 骨架：`animcurve/core.py`
- 题面：`prompt.txt`
- 自测：`python -m pytest tests -q`

## 方案

- **重建**：单调三次 Hermite（PCHIP 切线 + 割线钳制）。折返点（局部极值）切线自动归零，
  段内单调、不过冲；循环曲线首尾切线由首末段割线合成并强制相等，闭合处无速度跳变。
- **抽稀**：贪心一趟扫描，段内 Hermite 偏差超预算就把前一帧固定为关键帧；
  之后切线定型、量化，再对压缩结果做**精确**误差验证（误差函数是三次多项式，
  解析求临界点，不靠抽样），违例则插回最差关键帧直到满足上界 —— 不靠删帧换误差达标。
- **量化**：时间/数值量化到自适应网格（量化误差预算 ≤ 0.2·tol，含在总上界内）；
  端点时间保持原值避免定义域漂移；碰撞用 `nextafter` 顶开，不重排、不产生重复时间戳。

## 实测

`python -m animcurve.cli data/curves.json --out packed.json`（tol = 0.02）：

```json
{"before": 7, "after": 7, "max_dev": 0.0, "ratio": 1.0}
```

| 指标 | 值 |
|---|---|
| 原始帧数 | 7 |
| 压缩后帧数 | 7 |
| 最大偏差 | 0.0 |
| 压缩率 | 1.0 |

`data/curves.json` 每一帧都是局部极值（相邻帧跳变 0.7–1.0，远超 tol=0.02），
删掉任何一帧都会在该时刻产生 ≥0.35 的偏差，所以诚实的输出是一帧不删，而不是删帧假装达标。

光滑信号（`sin(2πt)+0.2·sin(6πt)`，tol=0.02）上的抽稀效果与密度缩放：

| 关键帧数 | 保留 | 压缩率 | 最大偏差 | 耗时 |
|---|---|---|---|---|
| 500 | 37 | 0.074 | 1.98e-02 | 12.7ms |
| 1000 | 41 | 0.041 | 1.94e-02 | 46.6ms |

**关键帧数翻倍时压缩率的变化**：保留关键帧数由信号特征（极值点、曲率）决定，
与采样密度基本无关（37 → 41），所以采样翻倍后压缩率近似翻倍（0.074 → 0.041），
误差上界始终是同一个 tol，不靠提高上界换压缩率。

规模：12 条曲线 × 500 关键帧（平坦段与陡变段混排），压缩 + 重建校验约 0.3s（上界 3s），
平坦段与陡变段适用同一误差上界（见 `tests/test_animcurve.py::test_scale_performance`）。
